# Security Policy

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

Email **info@molecare.co.uk** with what the issue is, how to reproduce it, and the affected
commit. You can expect an acknowledgement within a few days.

## Credentials

If you find any credential, key or token in this repository or its git history, report it
privately by email rather than opening an issue.

## Clinical safety

This repository is **not a medical device** and must not be used for diagnosis or triage.
If you believe a model or endpoint here could cause clinical harm — for example by being
presented to end users as diagnostic — please raise it privately by email so it can be
addressed quickly.
